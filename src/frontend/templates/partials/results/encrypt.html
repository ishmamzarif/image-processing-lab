Correlation is between each pixel and its right-hand neighbour: a photo sits near 0.9, because one pixel nearly tells you the next, and noise sits near 0. Entropy is of the 8-bit histogram, where 8.00 means every value is equally likely{% if not real_cipher %} — |E| falls short of it honestly, since the magnitude of a complex field with random phase is Rayleigh distributed, not flat{% endif %}. Size is the ciphertext: {% if real_cipher %}one byte per channel, the same as the raw image, plus the handful of bytes of tags inside the PNG{% else %}a complex128 field, 16 bytes a channel, which is the price of a ciphertext that is not an image{% endif %}.

Worth saying plainly: this is the Fourier transform used as a cipher, not a cipher you should use. Double random phase encoding is a real scheme and a landmark one, but it is linear, and a linear cipher falls to a known-plaintext attack — a few plaintext-ciphertext pairs are enough to solve for the masks. The passphrase is hashed once with sha256, which is not a key derivation function either.
