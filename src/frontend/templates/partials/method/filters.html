Equations

{% if filter_kind == 'grayscale' %}
①
Y = 0.299\,R + 0.587\,G + 0.114\,B
return 0.299 * r + 0.587 * g + 0.114 * b
How bright the pixel looks, as one number. Green counts most and blue least, because that is how sensitive the eye is to each; these are the weights Pillow's convert("L") uses too.
②
\mathrm{out}_c = \mathrm{in}_c + t\,(Y - \mathrm{in}_c), \qquad t = {{ gray_amount }}
out[y, x, c] = image[y, x, c] + amount * (gray - image[y, x, c])
A straight-line mix between the pixel and its grey: t = 0 leaves it alone, t = 1 makes all three channels equal to Y, and in between the colour fades. Every channel moves towards the same Y, so the brightness stays roughly where it was.
③
\mathrm{dst}_c[y,x] = \big\lfloor \operatorname{clip}(\mathrm{out}_c[y,x],\ 0,\ 255) \big\rfloor
filtered = np.clip(filtered, 0, 255).astype(np.uint8)
The floor is astype, which truncates rather than rounds.
{% elif filter_kind == 'invert' %}
①
\bar{v} = 255 - v
opposite = 255 - image[y, x, c]
The opposite end of the channel's range: black becomes white, and a strong red becomes a weak one. Done on all three channels, that turns every colour into its complement.
②
\mathrm{out}_c = \mathrm{in}_c + t\,(\bar{v}_c - \mathrm{in}_c), \qquad t = {{ invert_amount }}
out[y, x, c] = image[y, x, c] + amount * (opposite - image[y, x, c])
The same mix as the other filters. At t = 0.5 every channel lands on 127.5, which is why a half-inverted picture is flat grey.
③
\mathrm{dst}_c[y,x] = \big\lfloor \operatorname{clip}(\mathrm{out}_c[y,x],\ 0,\ 255) \big\rfloor
filtered = np.clip(filtered, 0, 255).astype(np.uint8)
The floor is astype, which truncates rather than rounds.
{% elif filter_kind == 'black_and_white' %}
①
Y = 0.299\,R + 0.587\,G + 0.114\,B
return 0.299 * r + 0.587 * g + 0.114 * b
How bright the pixel looks, as one number. Green counts most and blue least, because that is how sensitive the eye is to each; these are the weights Pillow's convert("L") uses too.
②
\mathrm{out}[y,x] = \begin{cases} 255 & Y \ge T \\ 0 & Y < T \end{cases}, \qquad T = {{ threshold }}
if gray_of(r, g, b) >= threshold:
    out[y, x] = 255
else:
    out[y, x] = 0
A threshold: every pixel becomes pure white or pure black, on all three channels, so only two colours are left. A lower T turns more of the picture white.
③
\mathrm{dst}_c[y,x] = \big\lfloor \operatorname{clip}(\mathrm{out}_c[y,x],\ 0,\ 255) \big\rfloor
filtered = np.clip(filtered, 0, 255).astype(np.uint8)
The floor is astype, which truncates rather than rounds. Here every value is already 0 or 255, so this changes nothing.
{% elif filter_kind == 'pixelate' %}
①
\bar{c}_T = \frac{1}{|T|} \sum_{(y,x) \in T} \mathrm{in}_c[y,x], \qquad T = \text{one tile of up to } {{ block }} \times {{ block }}
for y in range(top, bottom):
    for x in range(left, right):
        for c in range(3):
            total[c] += image[y, x, c]
count = (bottom - top) * (right - left)
The image is cut into square tiles, starting at the top-left. Each tile's pixels are added up channel by channel and divided by how many there are. Tiles on the right and bottom edges are smaller when the size does not divide evenly, and they are averaged over the pixels they actually have.
②
\mathrm{out}_c[y,x] = \bar{c}_T \quad \text{for every } (y,x) \in T
out[y, x, c] = total[c] / count
Every pixel in the tile gets the tile's average, so the detail inside a tile is gone and only its overall colour is left. Unlike the other filters, a pixel's new colour depends on its neighbours.
③
\mathrm{dst}_c[y,x] = \big\lfloor \operatorname{clip}(\mathrm{out}_c[y,x],\ 0,\ 255) \big\rfloor
filtered = np.clip(filtered, 0, 255).astype(np.uint8)
The floor is astype, which truncates rather than rounds.
{% elif filter_kind == 'vintage' %}
①
\begin{pmatrix} S_R \\ S_G \\ S_B \end{pmatrix} = \min\left(255,\ \begin{pmatrix} 0.393 & 0.769 & 0.189 \\ 0.349 & 0.686 & 0.168 \\ 0.272 & 0.534 & 0.131 \end{pmatrix} \begin{pmatrix} R \\ G \\ B \end{pmatrix} \right)
sepia_r = min(255.0, 0.393 * r + 0.769 * g + 0.189 * b)
sepia_g = min(255.0, 0.349 * r + 0.686 * g + 0.168 * b)
sepia_b = min(255.0, 0.272 * r + 0.534 * g + 0.131 * b)
The classic sepia matrix. Each row mixes all three channels, and the rows get smaller from red to blue, so every colour comes out as a warm brown of about the same brightness. The top row adds up to more than 1, so bright pixels can pass 255; each is capped there.
②
\mathrm{out}_c = \mathrm{in}_c + t\,(S_c - \mathrm{in}_c), \qquad t = {{ vintage_amount }}
out[y, x, c] = image[y, x, c] + amount * (sepia[c] - image[y, x, c])
The same mix as grayscale, towards the sepia tone instead of the grey: t = 1 is full sepia, and lower values keep some of the original colour.
③
\mathrm{dst}_c[y,x] = \big\lfloor \operatorname{clip}(\mathrm{out}_c[y,x],\ 0,\ 255) \big\rfloor
filtered = np.clip(filtered, 0, 255).astype(np.uint8)
The floor is astype, which truncates rather than rounds.
