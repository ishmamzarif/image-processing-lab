Equations

①
\tilde{E} \in \lbrace 0,\dots,255 \rbrace^{M \times N \times 3}, \qquad M = 2^{a},\ N = 2^{b}
img = Image.open(file.stream)
img.load()
text = dict(getattr(img, "text", {}) or {})
Opened at its own size, unlike every other page here. A photograph can be shrunk to fit the working size; a ciphertext cannot be resampled at all — every pixel of it is a sum over every pixel of the original, so touching one damages all of them. Its size is data, not a detail, and a picture whose sides are not powers of two was not made by the encoder.
②
\text{tEXt} \ \longrightarrow \ \big(\text{cipher},\ (\ell, h),\ (H, W)\big)
TAG_SCHEME = "ipl-cipher"
TAG_LOW = "ipl-low"
TAG_HIGH = "ipl-high"
Three things besides the key are needed to read a ciphertext, and none of them is secret: which cipher made it, the stretch that fitted it into 0–255, and the size to crop back to. Encrypt writes them into the PNG as text chunks, so they travel inside the picture. It is the envelope, not the letter: anyone holding the file can read all of it and still have no way to open it.
③
E = \frac{\tilde{E}}{255}\,(h - \ell) + \ell
return picture.astype(np.float64) / 255.0 * (high - low) + low
The stretch undone, which puts the 8-bit picture back on the scale the cipher field was on. This is the one lossy step in the whole round trip: the values were rounded to 256 levels when the file was written, and that rounding is what stops the recovery being exact.
④
R = e^{\,2\pi i\,r}, \qquad r \ \text{seeded by} \ \operatorname{sha256}(\text{purpose} : \text{key})
spatial, frequency = masks(key, scheme, cipher.shape[:2])
The same masks the encryption drew, rebuilt from the same passphrase by the same code in common/phase_keys.py. That shared file is the whole reason the two halves agree: neither can change how a mask is drawn without the other following.
⑤
\psi = \overline{R_1} \cdot \mathcal{F}^{-1}\big\lbrace \mathcal{F}\lbrace E \rbrace \cdot \overline{R_2} \big\rbrace, \qquad R\overline{R} = |R|^2 = 1
out[:, :, c] = ifft2(fft2(cipher[:, :, c]) * np.conj(frequency)) * np.conj(spatial)
Conjugating a unit-magnitude mask inverts it, so this is the encryption's own steps with the masks conjugated and run in the opposite order. Nothing was discarded going in — no bin zeroed, no magnitude rounded — so the only error is float round-off, about 10⁻¹⁶, and the quantisation from ③.
⑥
\tilde{x} = \operatorname{clip}\big(\Re\,\psi,\ 0, 1\big) \ \text{(phase)}, \qquad \tilde{x} = \operatorname{clip}\big(|\psi|,\ 0, 1\big) \ \text{(drpe)}
pixels = np.real(field) if scheme == "phase" else np.abs(field)
return np.clip(pixels, 0.0, 1.0)
Which part of a complex field is the picture. With the right key the two readings agree exactly, because the recovered field is then the image itself: real, and never negative. They part company only when the key is wrong — and there the magnitude is the honest answer, since a failed decryption comes back zero-mean and clipping its real part would floor half the plate to black.
⑦
\mathcal{D}(\alpha E + \beta) = \alpha\,x + \beta \quad \Longrightarrow \quad \frac{\tilde{x} - \min \tilde{x}}{\max \tilde{x} - \min \tilde{x}} \approx x
low, high = float(image.min()), float(image.max())
return (image - low) / (high - low)
The fallback for a file that carried no tags. Decryption is linear and a flat image comes back as itself, so decrypting the stretched picture rather than the field gives an affine of the photo — the right picture at the wrong brightness and contrast. One more stretch undoes it. The crop cannot be guessed the same way, so such a result keeps its padding.
