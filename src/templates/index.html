def box_kernel(size):
    return np.ones((size, size), dtype=np.float64) / (size * size)

                            Box kernel. Every weight equal, and summing to 1 so the average brightness is unchanged.

\tilde{K}[i,j] = K[\,k-1-i,\ k-1-j\,]


kernel = kernel[::-1, ::-1]

\begin{aligned} \mathrm{pad}[y,x] &= \mathrm{src}\big[\operatorname{clamp}(y-p,\,0,\,H-1),\ \operatorname{clamp}(x-p,\,0,\,W-1)\big] \\ p &= \lfloor k/2 \rfloor \end{aligned}

                            The continuous transform, evaluated by the trapezoidal rule (np.trapezoid) rather than by a DFT. Split into cos and sin parts so it stays in real arithmetic.

                            Back to the image. What survives is only the fast-changing part — edges and texture.

def pixel_loss(a, b):
    diff = np.abs(a.astype(np.int16) - b.astype(np.int16))
    return 100.0 * float(np.mean(diff)) / 255.0

                            A sinusoid is a handful of points in the spectrum. Gaussian grain is spread evenly over all of it — which is exactly why one is removable and the other is not.

                            The 2D transform is separable: the bracket is a transform of one row, and the outer sum is then a transform down each column of that result.
