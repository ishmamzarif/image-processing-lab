Equations

{% if blurred %}
①
K[i,j] = 1 / k² Box kernel. Every weight equal, and summing to 1 so the average brightness is unchanged.
②
K̃[i,j] = K[k−1−i, k−1−j] The flip is what makes this convolution rather than correlation. A box kernel is symmetric, so here it changes nothing.
③
pad[y,x] = src[clamp(y−p, 0, H−1), clamp(x−p, 0, W−1)],   p = ⌊k/2⌋ Replicating the border keeps the output the same size as the input.
④
out[y,x] = Σky=0k−1 Σkx=0k−1 pad[y+ky, x+kx] · K̃[ky,kx] One multiply-accumulate per kernel cell, per output pixel, per channel. Cost is O(H·W·k²) — which is why the times climb with k.
⑤
clip(·, 0, 255) → uint8 astype truncates rather than rounds, which is the whole of the difference from Pillow.
{% elif sharpened or edges %} {% if edges %}
①
L = 0.299·R + 0.587·G + 0.114·B,   L ← L / max(L) ITU-R 601-2 luma, then scaled to 0…1.
{% endif %}
{% if edges %}—{% else %}①{% endif %}
x = linspace(−1, 1, W),   y = linspace(−1, 1, H) The image is treated as a function on a continuous square, not as a sequence of samples.
{% if edges %}—{% else %}②{% endif %}
u ∈ [ −1/(2Δx), 1/(2Δx) ],   v ∈ [ −1/(2Δy), 1/(2Δy) ] The Nyquist limit: the highest frequency a grid of this spacing can carry.
③
F(u,v) = ∬ f(x,y) · e−2πi(ux+vy) dx dy The continuous transform, evaluated by the trapezoidal rule (np.trapezoid) rather than by a DFT. Split into cos and sin parts so it stays in real arithmetic.
④
F′(u,v) = F(u,v) · [ 1 − e−D(u,v)² / 2D₀² ],   D = √( (v/Δv)² + (u/Δu)² ) A Gaussian low-pass subtracted from everything, which is unsharp masking done in the frequency domain. The edge has to be smooth: a hard circle here is a sinc in the image, so every edge would come back wrapped in ripples spreading across the whole picture. The radius is measured off the u and v axes rather than off array indices, because linspace(−N, N, even) has no exact zero bin to centre on.
⑤
detail(x,y) = ∬ F′(u,v) · e+2πi(ux+vy) du dv Back to the image. What survives is only the fast-changing part — edges and texture.
{% if edges %}
⑥⑦
E = |detail| / max|detail|,   out = 1 − E Magnitude, normalised, then inverted so edges are dark on white.
{% else %}
⑥
g(x,y) = f(x,y) + amount · detail(x,y) The detail is added back on top. Past about 2 it overshoots and haloes appear along strong edges. A Gaussian of spatial width r matches a frequency width N/(2πr), which is how the Pillow radius below is derived rather than guessed.
{% endif %} {% else %}
①
n(x,y) = A · sin( 2π( fx·x/W + fy·y/H ) )  and / or   𝒩(0, σ²) A sinusoid is a handful of points in the spectrum. Gaussian grain is spread evenly over all of it — which is exactly why one is removable and the other is not.
②
reflect-pad to M, N = next_power_of_two(H), next_power_of_two(W) Radix-2 needs a power of two. Reflecting rather than zero-filling avoids a hard edge, which would be a step, and a step is broadband — it would scatter energy over the whole spectrum and bury the peaks.
③
X[u,v] = Σm e−2πi·um/M [ Σn x[m,n] · e−2πi·vn/N ] The 2D transform is separable: the bracket is a transform of one row, and the outer sum is then a transform down each column of that result.
④
X[k] = E[k] + WNk·O[k],   X[k+N/2] = E[k] − WNk·O[k],   WN = e−2πi/N The radix-2 butterfly. Splitting even from odd indices turns O(N²) into O(N log N); the inverse reuses it as conj(transform(conj(X)))/N.
⑤
{% if filt == 'notch' %} M[u,v] = Πp ( 1 − e−Dp²/2σ² ),   Dp = distance to peak p A hole at each detected peak. A peak counts as noise when it exceeds 4× the 99.9th percentile of the rest of the spectrum — measured, a real sinusoid reaches about 13× and pure grain only 1.8×. {% elif filt == 'gaussian' %} M[u,v] = e−D(u,v)² / 2σ²,   D = √((u−N/2)² + (v−M/2)²) Fades out with distance from the centre instead of cutting. No ringing, but everything fine gets attenuated. {% else %} M[u,v] = [ D(u,v) ≤ D₀ ] A hard circle. The sharp edge in frequency is a sinc in the image, which is where the ringing around edges comes from. {% endif %}
⑥
Xclean[u,v] = Xnoisy[u,v] · M[u,v] Filtering is a single multiply in the frequency domain — the same operation that would be an expensive convolution in the image domain.
⑦
x[m,n] = (1/MN) Σu Σv X[u,v] · e+2πi(um/M + vn/N) Back to the image, and the imaginary part is discarded — it is round-off, since the input was real.
dB
PSNR = 10 · log₁₀( 1 / MSE ),   MSE = mean( (a − b)² ) Reported against the clean original, so the two figures above say how much of the damage was undone. Higher is better; +6 dB is roughly halving the error.
